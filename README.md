# 🪑 AI-Помощник для первичной обработки входящих заявок (MVP)

Интеллектуальный веб-помощник для менеджеров мебельной компании (продажа столов, кресел, шкафов, доставка и сборка). Приложение автоматически анализирует текст входящих писем и сообщений от клиентов, квалифицирует лид, извлекает важные параметры и готовит готовый проект ответа.

---

## 🌟 Что умеет помощник

1. **Квалифицировать запрос:**
   - **Целевой** — клиент интересуется офисной мебелью, доставкой или сборкой с намерением покупки.
   - **Нецелевой** — запрос не относится к профилю компании.
   - **Неясно** — слишком мало данных для однозначного вывода.
2. **Защищать персональные данные (Анонимизация):** автоматически находит имена, телефоны, email и адреса, заменяет их на временные токены перед отправкой в нейросеть (`[ИМЯ_1]`, `[ТЕЛЕФОН_1]`...), хранит таблицу только в оперативной памяти запроса и восстанавливает реальные данные в итоговой карточке.
3. **Извлекать известные параметры:** компанию, продукцию, количество, бюджет, сроки, контакты (ничего не выдумывая — если данных нет, честно пишет «не указано»).
4. **Фиксировать недостающие данные:** подсказывает менеджеру, каких параметров не хватает для расчета сметы.
5. **Определять необходимость срочного подключения человека:** если клиент жалуется на срыв сроков, требует возврат денег или возник конфликт — выведет предупреждение менеджеру и причину эскалации.
6. **Готовить черновик ответа:** формирует вежливый текст с уточняющими вопросами или нейтральное подтверждение приема претензии без несогласованных обещаний. Черновик можно скопировать в буфер обмена одной кнопкой.

## 🛠 Используемые технологии (простыми словами)

Вам не нужно быть программистом, чтобы запустить этот проект. Стек выбран максимально простой и надёжный:
- **Python** — язык программирования, на котором работает серверная логика (у вас уже установлен).
- **Flask** — компактный веб-сервер. Он принимает запрос из браузера и передаёт его дальше.
- **Модуль Anonymizer (anonymizer.py)** — локальный слой защиты конфиденциальности, скрывающий персональные данные до передачи во внешние API.
- **Официальная библиотека GigaChat** — официальный компонент от Сбера для прямого безопасного общения с искусственным интеллектом GigaChat.
- **python-dotenv** — инструмент для безопасного хранения секретных ключей доступа в отдельном файле `.env`.
- **HTML + CSS + JavaScript** — наглядная страница в браузере с интерактивной формой ввода (имя, телефон, компания, суть заявки), кнопками быстрых тестов и цветными индикаторами.

## 🚀 Пошаговая инструкция по запуску

### Шаг 1. Установите необходимые библиотеки
Откройте терминал (PowerShell или Командную строку) в папке проекта и выполните команду:
```bash
pip install -r requirements.txt
```
*Что это делает:* скачивает и устанавливает 3 нужные библиотеки (`flask`, `gigachat`, `python-dotenv`).

---

### Шаг 2. Настройте файл с ключом доступа (.env)
1. В папке проекта найдите файл **`.env.example`**.
2. Создайте его копию и назовите её строго **`.env`** (с точкой в начале).
3. Откройте файл **`.env`** в любом текстовом редакторе (Блокнот, VS Code и т.д.).
4. В строке `GIGACHAT_CREDENTIALS=` вставьте ваш ключ авторизации (Base64), полученный в личном кабинете [Сбер Studio](https://developers.sber.ru/studio/).

Пример заполненной строки:
```env
GIGACHAT_CREDENTIALS=MDE5OWI5ZTQt...ваша_длинная_строка_ключа_авторизации...
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
GIGACHAT_VERIFY_SSL_CERTS=false
```

> **Важно:** 
> - Файл `.env` уже добавлен в `.gitignore`. Никогда не передавайте ключ посторонним и не публикуйте его в интернете.
> - Не отправляйте секретные ключи в чаты с AI.

---

### Шаг 3. Запустите приложение
В терминале выполните команду:
```bash
python app.py
```
В терминале появится сообщение:
```text
============================================================
 AI-помощник обработки входящих заявок запущен!
 Откройте в браузере: http://127.0.0.1:5000
 Для остановки нажмите Ctrl + C
============================================================
```

---

### Шаг 4. Откройте приложение в браузере
Перейдите по адресу:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 🧪 Проверка работы на 3 тестовых сценариях

В верхней части экрана есть 3 удобные кнопки для моментальной вставки тестовых запросов:

1. **Кнопка 1. «Альфа-Логистик» (40 мест, 1.5 млн руб)**
   - *Сценарий:* Полная заявка от компании.
   - *Результат:* Лид квалифицируется как **«Целевой запрос»**, эскалация человеку не требуется, в известных параметрах выделены бюджет (1.5 млн руб), 40 рабочих мест, переезд в следующем месяце. В Битрикс24 создаётся Лид с суммой 1,5 млн руб и отправляется уведомление менеджеру.

2. **Кнопка 2. «Сколько стоят кресла?»**
   - *Сценарий:* Неполная заявка без бюджета, сроков и контактов.
   - *Результат:* Лид определяется как целевой или требующий уточнения, в блоке *«Чего не хватает»* подсвечены количество, модели и контакты. В Битрикс24 создается Лид с уточняющими вопросами.

3. **Кнопка 3. «Срыв доставки и возврат денег»**
   - *Сценарий:* Конфликтное обращение, задержка заказа, угроза расторжения.
   - *Результат:* Срабатывает красное предупреждение **«⚠️ Требуется менеджер»** с указанием причины. В Битрикс24 создаётся Лид, **ставится срочная Задача (High priority)** с привязкой к лиду и приходит тревожное уведомление.

## 🏢 Интеграция с Битрикс24 (CRM, Задачи, Уведомления)

Приложение автоматически передает обработанные заявки в ваш корпоративный портал Битрикс24 через входящий вебхук:
- **`B24_URL` в `.env`:** URL входящего вебхука вида `https://ваш-портал.bitrix24.ru/rest/1/ключ_вебхука/`
- **Создание лидов (`crm.lead.add`):** все заявки автоматически попадают в список лидов CRM с заполненными контактами, бюджетом и структурированным описанием от AI.
- **Постановка задач (`tasks.task.add`):** при любых конфликтах или жалобах (`needs_human: true`) менеджеру автоматически ставится задача с высоким приоритетом и привязкой к лиду.
- **Мгновенные уведомления (`im.notify.personal.add`):** уведомления приходят прямо в колокольчик в портале Битрикс24 с кликабельными ссылками на карточку лида и задачу.

## 🔒 Безопасность и защита персональных данных
- **Анонимизация перед отправкой в AI:** Имена, номера телефонов, электронные почты и адреса автоматически заменяются на временные токены. Внешняя нейросеть Сбера никогда не видит реальные персональные данные ваших клиентов.
- **Хранение только в оперативной памяти:** Таблица соответствия токенов и реальных данных существует только миллисекунды во время обработки текущего запроса и удаляется из памяти сразу после возврата ответа.
- **Безопасность API-ключей:** Все обращения к GigaChat и вебхуку Битрикс24 происходят на вашем сервере (бэкенде). Клиентский браузер не имеет прямого доступа к API-ключам, а файл `.env` исключен из системы контроля версий.
